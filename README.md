# 게젤샤프트

림버스 컴퍼니 덱 빌더, 인격·E.G.O·기프트·적 정보 검색, 딜 계산기를 한곳에 모은 비공식 팬 도구입니다.

사이트: https://mori365.github.io/gesellschaft/

## 메뉴

- **덱 빌더**: 수감자별 인격·E.G.O·스킬 보유수를 편성하고, 현재 편성에서 발동 가능한 패시브를 계산합니다.
- **스킬셋**: 인격별 스킬 1/2/3/수비의 죄악 속성과 E.G.O 스킬을 확인하고 필터링합니다.
- **서폿패**: 전 수감자의 서포트 패시브를 검색하고 필터링합니다.
- **기프트**: 거울 던전 E.G.O 기프트를 키워드별로 보고, 조합법과 조합 재료로 쓰이는 곳을 확인합니다.
- **적**: 챕터별 적의 스탯·내성·스킬·패시브를 봅니다. 페이즈와 하위 개체는 한 카드로 묶어서 보여줍니다.
- **딜뽕 계산기**: 편성한 스킬 한 방의 최대 데미지를 계산합니다.
  - 이번 턴 슬롯을 가로로 늘어놓고(드래그로 순서 변경), 슬롯을 누르면 그 스킬의 딜을 보여줍니다.
  - 인격 레벨·동기화 단계, E.G.O 해석 단계(각성/침식), 적 여러 명 동시 선택(총합), 합 완승 여부를 반영합니다.
  - 자신·적 키워드 스택, 장착 E.G.O 기프트를 기록할 수 있습니다. 전용 키워드는 인격·기프트에 맞춰 자동으로 추가됩니다.
  - 크리에이티브 모드는 게임 규칙(E.G.O 턴당 1회, 합성 기프트 재료 소모 등)을 따르고, 버그판 모드는 규칙을 무시하고 자유롭게 설정합니다.
  - 기프트·패시브처럼 조건이 제각각인 효과는 자동 반영하지 않고, "기타 보정치"에 직접 넣도록 되어 있습니다.

## 그 밖의 기능

- 키워드 툴팁과 아이콘
- 검색창마다 "이름만 검색" 토글
- 보유 인격·E.G.O 관리 (브라우저 localStorage에 저장)
